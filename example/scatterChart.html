Chart.js Trendline Plugin

Scatter Chart with Linear Trendline

What to Look For

The trendline is the least-squares fit through all nine points, not a line through the first and last one. The points scatter around it, and the label prints the fitted slope.

  • Data shape: each point is {x, y}; the plugin reads those keys by default
  • Fit: slope ≈ 1.82 — roughly +1.8 in y per unit of x
  • Label: displayValue: true appends the slope to the label text
